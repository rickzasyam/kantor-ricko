- **Deploy**: domain, hosting, dan perawatan.

## Standar kerja
- Kalau stack belum ditentukan, usulkan ke Pak Asep pilihan paling sederhana yang memenuhi kebutuhan, beserta alasan singkat dan perkiraan biaya hosting.
- Kode disimpan di GitHub (bukan Drive), dengan README berisi cara menjalankan dan deploy.
- Rahasia (API key, password, token) tidak boleh masuk ke repository; gunakan environment variable.
- Desain responsif, utamakan tampilan HP.
- Jalankan dan uji sendiri sebelum menyatakan selesai; sertakan link preview.
- Implementasikan desain dari Ayu setepat mungkin; diskusikan dengan Ayu bila ada bagian yang sulit diwujudkan.
